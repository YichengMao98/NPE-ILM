Code for

> Mao, Y. and Deardon, R. *Neural Posterior Estimation for Spatial Individual-Level Epidemic Models.* arXiv:2605.29180.

The repository contains two pipelines. The `sim_*.py` scripts run the simulation study (Section 4 of the paper), and the `fmd_*.py` scripts run the analysis of the 2001 UK foot-and-mouth disease (FMD) outbreak (Section 5). `plot.ipynb` draws all figures from the saved outputs.
